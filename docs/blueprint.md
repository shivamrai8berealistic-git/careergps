# **App Name**: CareerPilot AI

## 🚀 Core Features (Launch Version):

### 1) Job discovery / input methods
- **Input Options:** Upload Resume, Upload Resume + Describe needs in plain language, or just Describe needs in plain language.
- **Import Methods:** Job URL / Extension job import, Upload JD import.

### 2) Resume / profile creation
- **Resume Import:** With structured data extraction.
- **Profile Builder:** Centralized profile management.
- **Tailored Resume Recruiter:** One-click current resume rewriter.
- **Keyword Gap Analyzer:** Identify missing keywords in resumes.
- **Version Control:** Maintain resumes version-wise.
- **LinkedIn Profile Optimizer:** Tailored suggestions for LinkedIn.

### 3) Skill gap / ATS / career matching
- **Resume Enhancer:** Gap check and resume inconsistency checker.
- **Gap Finder:** Job and current skill gap finder with gap-filler resource recommendations.
- **ATS Score Engine:** Score resume against specific job and explain the gap.
- **Missing Skill Analyzer:** Detailed breakdown of required vs current skills.
- **Career Recommendation:** Match skill gaps to trusted learning options, ROI calculator for certifications, and AI skill graph.
- **Stream Shifting:** Preparation for new dream jobs (e.g., transitioning from Web Developer to Product Manager).
- **New Job Alerts:** Alerts for friends or for stream-shifting/new dream jobs.

### 4) Cover letter / salary / job insights
- **Cover Letters:** Job-specific cover letter generation.
- **Salary Band Preview:** Show likely range for the role, city, and experience.
- **Salary Insights:** Standard salary vs. Actual market pay vs. Actual company paying.
- **Salary Alerts:** Notifications on salary trends.

### 5) Coaching / guidance
- **Coach Avatar:** Interactive AI coach services.
- **Interview Preparation:** Tailored interview prep.
- **Salary Negotiation:** Coaching on negotiation tactics.
- **Voice Interview Practice:** Spoken answers, transcriptions, and feedback on clarity/structure.
- **Career Path Advisor:** Style guidance (e.g., "Should I move from Java Dev to PM?").
- **Upskilling Loop:** Shortest path to close gaps for the target role.

### 6) Application tracking / follow-up
- **Application Tracker:** Manage Saved / Applied / Interview / Rejected stages in one place.
- **Trigger Follow-up / Analyzer:** Select jobs on the tracker and automatically analyze status (e.g., expired, about to expire, X% skill gap filled).
- **WhatsApp Integration:** Status bot, job alerts, reminders, cron trigger follow-ups, application updates on WhatsApp.
- **Custom Reminders:** Auto-reminders for follow-ups, interviews, 2nd rounds, etc.
- **Duplicate Tracking:** Avoid duplicate applications.

### 7) Trust / safety
- **Trust & Safety Layer:** Scam detection, fee request blocking, misleading job detection, employer verification.

### 8) Alerts / sharing / engagement
- **WhatsApp Job-Forwarding:** "Forward to a friend" sharing flow.
- **Referrals:** Invite and referral program.
- **Alerts:** Based on saved searches.
- **Personalized Feed:** Tailored job feed.

### 9) Voice / search
- **Voice Interactions:** Voice search and usage (voice typing).

## 💰 Monetization & Security:

- **India-First Subscription Model**: Premium "Pro" plan at ₹299/month, optimized for the Indian market via Razorpay.
- **Server-Side Quota Enforcement**: Atomic credit tracking for AI flows (Job Analysis, Resumes, Cover Letters, etc.) to control API costs.
- **Usage Dashboard**: Real-time "Usage Meter" for users to track their monthly limits and upgrade status.
- **Integrated Payments**: Secure checkout flow with UPI, Card, and Netbanking support.
